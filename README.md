# বিডি ইমেজ রিসাইজার (BD Image Resizer)

চাকরি, বিসিএস, ব্যাংক নিয়োগ ও ভর্তির আবেদনের জন্য **ছবি ও স্বাক্ষর রিসাইজ + নির্দিষ্ট KB-তে কমপ্রেস** করার বাংলা-প্রথম, ১০০% ফ্রন্টএন্ড টুল।
কোনো ব্যাকএন্ড, ডেটাবেস বা আপলোড নেই — সব প্রসেসিং ব্রাউজারেই (Web Worker + Canvas) হয়।

## চালানো

```bash
npm install
npm run dev       # ডেভেলপমেন্ট
npm run build     # প্রোডাকশন বিল্ড → dist/
npm run preview   # বিল্ড প্রিভিউ
```
Node 18+ প্রয়োজন।

## Vercel-এ ডেপ্লয়
প্রজেক্ট GitHub-এ পুশ করে Vercel-এ Import করুন (Framework: Vite, Build: `npm run build`, Output: `dist`)। কোনো Environment Variable লাগে না।
`vercel.json`-এ SPA rewrite এবং কঠোর CSP (`connect-src 'self'`) আছে — ব্রাউজারই বাইরে ডেটা পাঠাতে দেবে না।

## ফিচার
- JPG/PNG/WebP আপলোড (ড্র্যাগ-ড্রপ, ক্লিক, পেস্ট), আসল ফাইল-টাইপ যাচাই
- প্রস্থ/উচ্চতা (বাংলা সংখ্যাও চলে), অনুপাত লক, 1:1 / 3:1 / 4:3 / 3:4 / 16:9 / মূল / কাস্টম
- ছবির জন্য ইন্টারঅ্যাকটিভ ক্রপ (বক্স টানা, জুম, কিবোর্ড); স্বাক্ষরের জন্য পুরো ছবি ফিট
- সর্বোচ্চ ও সর্বনিম্ন (ঐচ্ছিক) KB — পোর্টালের "4–100 KB" ধরনের নিয়ম মানতে
- KB সীমা: বাইনারি সার্চে কোয়ালিটি নির্ধারণ; **প্রকৃত Blob সাইজ মেপে** ফল দেখায়, পূরণ না হলে স্পষ্ট বাংলা ব্যাখ্যা
- JPEG/PNG আউটপুট (আপলোডে JPG/PNG/WebP চলে) (ফাঁকা/স্বচ্ছ অংশ সাদা রঙে ভরে)
- স্বাক্ষর মোড (পরিষ্কার করার অপশন), প্রিসেট তৈরি/এডিট/মোছা (শুধু প্রিসেট localStorage-এ)
- **PWA**: হোম স্ক্রিনে ইনস্টল (Android Chrome-এ এক ট্যাপ, iPhone-এ ধাপে ধাপে গাইড), প্রথমবারের পর অফলাইনেও চলে, অ্যাপ শর্টকাট (ছবি / স্বাক্ষর)
- ফেভিকন, অ্যাপ আইকন (192/512/maskable/Apple touch), OG শেয়ার ইমেজ — `public/` ও `public/icons/`-এ
- ডার্ক/লাইট থিম, মোবাইল স্টিকি ডাউনলোড বার, অ্যাক্সেসিবিলিটি (বাংলা লেবেল, কিবোর্ড)

## নোট
- ফন্ট Hind Siliguri `@fontsource` দিয়ে নিজস্বভাবে হোস্ট করা (বাইরের Google Fonts রিকোয়েস্ট নেই)।
- KB লক্ষ্য 1 KB = 1000 বাইট ধরে, তাই 1000 বা 1024 — দুই হিসাবেই সীমার ভেতরে থাকে।
- প্রিসেটের মাপ শুধু উদাহরণ; আবেদনের বিজ্ঞপ্তির মাপ ব্যবহার করুন।
- কাঠামো: `src/components`, `hooks`, `utils` (imageCore/Compression/Crop…), `workers/image.worker.js`, `data`, `pages/Home.jsx`।

## আইকন বদলাতে
`public/favicon.svg`, `public/icons/*.png`, `public/favicon-*.png`, `public/favicon.ico`, `public/og-image.png` প্রতিস্থাপন করুন। OG ইমেজের পূর্ণ URL দরকার হলে `index.html`-এ `og:image`-এ নিজের ডোমেইনসহ লিখুন।
